OAuth2 Server


This project is an implementation of an OAuth2 server. It's designed to provide companies and their users with secure access to resources via tokens. The server supports different features that can be toggled on and off for each company, and it also supports role-based access control and permissions for both companies and users.

Features
Company Registration: Companies can register and manage their own users.
User Management: Each company can have multiple users.
Feature Toggling: Each company can have different features that can be toggled on and off.
Role-Based Access Control: Both companies and users have roles and permissions to control access to resources.
Authorization Code Grant: The server supports the Authorization Code grant type for obtaining access tokens.
Tokens: The server uses tokens for authorizing access to resources.
Secret Keys: The server uses secret keys for additional security.
